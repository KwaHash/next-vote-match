### ご依頼：国民向けサイト seijiselect.jp の本実装（MVP・8月実装目標）

お世話になっております。
国民向けサイト（seijiselect.jp）を、初期リリース向けに**機能を絞り込んだMVP**として再設計しました。**2026年8月の実装**を目標に、本実装をお願いしたくご連絡します。
コンセプトは「**あなたに近い政策と候補者が、30秒でわかる**」。トップを30秒診断中心にし、メニューは5つに整理しています。
作り直しではなく**完成済みプロト流用→Supabase接続→Vercel公開**で進めます（未ログイン中心）。

**■ 対象**
- リポジトリ: `next-vote-match`（ブランチ `prototype` / タグ `proto-v1`）
- 仕様書: repo内 `docs/実装仕様書_国民側_MVP.md`（MVPスコープ・5メニュー・SupabaseSQL・実装順序・受入条件）
- 画面ごとの仕様: `PROTOTYPE_LOG.md` ／ 全体構想: `BACKLOG.md`（candidate-vote-match）
- 起動: `npm install` → `npx next dev`（画面は `app/prototype/` 配下、`/prototype` がMVPメニュー）

**■ MVP（5メニュー）**
1. 診断する（30秒 政策マッチング診断・登録不要・最重要）
2. 地域の課題（旧KPI/都道府県課題を統合）
3. 候補者を探す（選挙で選ぶ〔〒検索〕＋候補者一覧・検索。候補者比較は選挙内比較に統合）
4. 政策を知る・応援する（旧：政策一覧・政策別寄付。寄付は第2段階）
5. 透明化レポート

**■ 後回し（初期は非表示）**
月額で応援する／寄付レポート／世界と比べる日本（SEO記事化）／候補者プレミアム（candidate側へ）／データ販売（法人向けフッター）。

**■ 進め方（重要）**
- 画面は完成済みなので**作り直さない**でください。
- バックエンドは作らず **Supabase**、公開は **Vercel**、未ログイン中心。
- 保存処理は **`app/prototype/_store.ts` に集約済み**。この1ファイルを Supabase に差し替えるだけで全画面が繋がります。
- **AIはその都度呼ばない設計**：診断・比較はルールベース／事前生成、深掘りは「比較プロンプトをコピー→ユーザー自身のAIへ」。何万人が使ってもAPI費用が出ないようにしてください。

**■ 特に重要な「選挙で選ぶ」**
〒検索→実施中の選挙→**中立的な候補者比較**（政策一致度/実行力/透明性の3スコア・争点マップ・10視点・データ出所）。
「おすすめ」等の投票誘導表現は使わず、参考比較である旨と中立注意文を表示します。

**■ 今回やらないこと（別フェーズ）**
- 寄付・献金の**実決済・本人確認・法令対応**（記録/後回し）。
- **実AI（LLM）接続**（その都度は呼ばない。高度化は「取込時に一度だけ生成→保存→表示」の事前生成で）。
- スクレイピング、政府統計のリアルタイム接続、他サイト/admin統合。

**■ 注意点（中立性・法令）**
- 候補者は**公平に表示**し、**データ出所を明示**してください。
- **電子メールによる選挙運動は有権者は禁止**。投票日リマインダーは中立的な情報通知に限定（投票依頼を含めない）。
- 寄付・決済機能は**本人確認・法務確認後**に提供。各所に注意文（仕様書8章）。
- **選挙・候補者ロスターのアップロードは運営admin側**（CSV取込→審査→公開）。国民側は表示のみ。

まず仕様書 §「実装順序」の Phase 2 以降（診断強化→地域課題/ランキング→候補者一覧/詳細/選挙別比較→透明化/投票日リマインダー）の見積もり・8月着手の進め方をご相談させてください。よろしくお願いいたします。
